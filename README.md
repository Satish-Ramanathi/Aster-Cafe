# Aster Cafe and Kitchen ☕✨
> *Where Flavor Meets Comfort*

A complete, modern, premium responsive restaurant and cafe website crafted for **Aster Cafe and Kitchen** located in Anand Banjara Colony, Banjara Hills, Hyderabad.

---

## 🎨 Visual Identity & Color System
- **Primary Brand Purple**: `#4B006E` (Used for fixed navbar, brand elements, and section labels)
- **Dark Purple**: `#35004F`
- **Accent Gold / Warm Brown**: `#B77B43` & `#C58A4E` (CTA buttons, highlights, hover states, calendar badges)
- **Content Sections**: Pure White `#FFFFFF` and Soft Cream `#FAFAFA`
- **Footer**: Deep Black `#050505` with clean white typography
- **Typography**: `Poppins` & `Playfair Display` (Google Fonts)

---

## 🚀 Key Features

1. **Sticky Header & Brand Navigation**:
   - Deep purple navbar with custom SVG 10-petaled Aster floral emblem.
   - Smooth scroll-spy tracking sections (`HOME`, `SERVICES`, `ABOUT US`, `GALLERY`, `CONTACT US`).
   - Pill-shaped `CONTACT US` CTA button.
   - Fully responsive hamburger drawer menu for mobile and tablet devices.

2. **Hero Section**:
   - Full-width cafe interior visual with dark gradient overlay.
   - Centered gold-highlighted heading and subtext.
   - Interactive `Reserve a Table →` calendar CTA button.

3. **About Us Section**:
   - Two-column responsive layout with purple badge and brand story.
   - Authentic night photography of Aster Cafe & Kitchen's exterior and illuminated stairs in Banjara Hills.

4. **Services & Private Events**:
   - 4 equal-height rounded service cards:
     - **Birthday party**
     - **Bridal shower**
     - **Art work shops**
     - **Catering & Events**
   - Circular celebration icon container and direct table reservation button for each event.

5. **Interactive Photo Gallery & Lightbox**:
   - 3-column responsive layout showcasing cafe interiors, brand walls, mocktails, latte art, and gourmet dishes.
   - Filter tabs: `All Photos`, `Ambience & Interior`, `Food & Coffee`, `Special Moments`.
   - Fullscreen Lightbox modal with zoom animation, image captions, and keyboard navigation (`←`, `→`, `ESC`).
   - `View More →` button for expandable content.

6. **Interactive Reservation Modal**:
   - Booking modal for dining, birthdays, bridal showers, workshops, and catering.
   - Real-time client-side field validation.
   - Interactive confirmation screen displaying a unique booking reference code (e.g. `AST-829141`) with 1-click **Confirm via WhatsApp** integration.

7. **Floating WhatsApp Button**:
   - Fixed circular pulsing button at bottom-right for direct chat with Aster Cafe (`+91 8686745411`).

8. **4-Column Black Footer**:
   - Column 1: Brand mission & social media links (Facebook, Instagram, YouTube, LinkedIn, X).
   - Column 2: Event service quick links.
   - Column 3: Site navigation links.
   - Column 4: Contact details with click-to-call, click-to-email, and Google Maps address.

## 💻 Local Setup & Development

To view and run the project locally:

```bash
# Clone the repository
git clone https://github.com/Satish-Ramanathi/aster_cafe.git

# Navigate to project directory
cd aster_cafe

# Run using any local HTTP server, for example with Python:
python -m http.server 5500
```

Then open `http://localhost:5500` in your web browser.
